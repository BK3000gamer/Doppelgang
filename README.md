## Player controls [Keyboard] (Controller):

- [A] [D} or (LS): Run
- [SPACE] or (✕): Jump
- [J] or (L1): Climb
- [W] [A] [S] [D] or (LS): Directions
- [SHIFT] or (R2): Clone
- [SHIFT] + [SPACE] or (R2)+(✕): Launch
- [CTRL] or [R1]: Recall
- [E] [Q] or (D-PAD): Teleport
- [X] or (▢): Interact
- [ESC] or (〇): Return
- [R] or (△): Restart

## Debugging features:

- Keyboard test is for quick tests and doesn’t require a controller. If a controller is connected in this mode, it will default to player 2.
